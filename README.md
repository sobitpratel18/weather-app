# Weather App 🌦️

A responsive weather application that displays real-time weather
information for cities using the OpenWeatherMap API.

## Features

- Search weather by city
- Real-time weather information
- Temperature in Celsius/Fahrenheit
- Weather condition
- Humidity
- Wind speed
- Responsive design
- API integration
- Backend API endpoint

## Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
- OpenWeatherMap API
- Vercel

## Live Demo

https://weather-app-two-tau-70.vercel.app/

## How It Works

The application sends the requested city to the backend API.
The backend communicates with OpenWeatherMap and returns the
weather data to the frontend.
