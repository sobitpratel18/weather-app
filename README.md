#  Weather App

A responsive weather application that displays real-time weather information for any city using the OpenWeather API.

##  Live Demo

[View live Weather App](https://weather-app-two-tau-70.vercel.app)

##  Features

-  Search weather by city
-  Real-time temperature
-  Celsius / Fahrenheit conversion
-  Dynamic weather icons
-  Humidity information
-  Wind speed information
-  Search using the Enter key
-  Responsive design for mobile, tablet, and desktop
-  Serverless API for secure API-key handling

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- Vercel Serverless Functions
- Git & GitHub
